# Bloom — Plant Store

A responsive plant store landing page built with React and Vite.

## Features

- Mobile-first responsive layout
- CSS Grid and Flexbox
- Responsive breakpoints at 320px, 768px, 1024px and 1440px
- CSS custom properties for design tokens
- Light and dark themes
- Glassmorphism effects
- Soft shadows and hover transitions
- No horizontal scrolling on mobile
- Responsive plant collection cards

## Tech Stack

- React
- Vite
- CSS
- JavaScript

## Responsive Design

The layout adapts across mobile, tablet and desktop screen sizes using CSS media queries and a mobile-first approach.

## Theme

Bloom includes both light and dark themes using CSS custom properties. The theme changes across the entire interface, including the background, cards, text, buttons and navigation.

## Project

Built as part of a responsive design and CSS architecture internship task.
